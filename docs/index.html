Stack de Ingeniería y Programación

¿Con qué tecnología se construyó Connecting?

Diseñado enfocándose en velocidad nativa pura, cero dependencias pesadas y máxima portabilidad.

Cliente Nativo

C# (.NET Framework 4.8 / Win32 API)

Cliente compilado nativamente en un único archivo ejecutable portátil de ~100 KB. Sin instaladores ni dependencias externas.

Entrada y Eventos

Inyección Nativa Win32 API

Inyección SendInput con coordenadas absolutas de pantalla y mapeo de códigos de escaneo físico (MapVirtualKey).

Servidor Relay

Motor TCP Sockets en Node.js

Servidor Relay privado On-Premise ligero escrito en Node.js para enrutamiento directo de sockets con cero bufer.
