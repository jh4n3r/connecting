Guía de instalación Linux

Compilar e instalar desde el código fuente (Linux)

Clona el repositorio, asigna permisos de ejecución a los scripts y compila el cliente nativo para Linux en minutos.

1. Clonar el repositorio y navegar a build/linux:
git clone https://github.com/jh4n3r/connecting.git cd connecting/build/linux
2. Dar permisos de ejecución a los scripts (chmod +x):
chmod +x combine.sh build.sh
3. Ejecutar los scripts de combinación y compilación:
./combine.sh ./build.sh
4. Lanzar la aplicación cliente ConnectingApp:
# Ejecutar en modo cliente / GUI: ./ConnectingApp # Ver todos los comandos de ayuda disponibles: ./ConnectingApp --help # Ejecutar como servicio de fondo (connecting-service): ./ConnectingApp --service
Servicio Linux & comandos: El binario compilado se lanza como ConnectingApp en modo cliente, o como daemon en segundo plano con --service (connecting-service). Ejecuta ./ConnectingApp --help para ver todas las opciones disponibles.
