Documentación Técnica Oficial - Connecting

Connecting Remote Desktop es una plataforma ligera, portátil y cifrada de asistencia y escritorio remoto en tiempo real desarrollada en C# (.NET Framework 4.8) con servidor de relevo de sockets TCP nativo en Node.js.

¿Por qué Connecting Enterprise? Permite desplegar tu propio servidor Relay privado On-Premise dentro de tu infraestructura de TI con Nginx + SSL, garantizando el aislamiento total de datos en redes corporativas sin enviar información a servidores externos.

Stack Tecnológico Oficial

Connecting ha sido diseñado enfocándose en el rendimiento y cero dependencia de librerías de terceros pesadas:

  • Cliente Windows C# (.NET Framework 4.8): Compilado con csc.exe a un ejecutable portátil nativo de ~65 KB. No requiere instalador ni servicios de fondo.
  • Motor de Entrada Win32 Native API (SendInput + MapVirtualKey): Inyección nativa de ratón (coordenadas absolutas 0 a 65535) y mapeo de códigos de escaneo físico de teclado para interactuar con herramientas elevadas como Administrador de Tareas, CMD, PowerShell y UAC.
  • Servidor Relay Node.js (TCP Socket Server Nativo): Enrutador de paquetes binarios de alta velocidad sin dependencias externas ejecutado en servidor Linux o servidor privado On-Premise.

Guía de Despliegue On-Premise (Servidor Privado)

Para empresas y departamentos de TI que requieren gestionar conexiones remotas dentro de una red privada aislada (VPN Corporativa o Red Local) utilizando el asistente de despliegue `setup-nginx-ssl.sh`:

1. Requisitos del Servidor

  • Sistema Operativo: Linux (Ubuntu Server 20.04/22.04 LTS o Debian).
  • Entorno de Ejecución: Node.js v16.0.0 o superior.
  • Servidor Web & SSL: Nginx y Certbot (instalados automáticamente por el asistente).
  • Puertos Abiertos: Puerto HTTP 80, HTTPS 443 y puerto de Relevo TCP 8443.

2. Configuración Automatizada con setup-nginx-ssl.sh

Ejecuta el asistente de configuración Dual (Landing Web + Proxy WebSocket de Relevo):

# 1. Conceder permisos de ejecución al script de asistente chmod +x setup-nginx-ssl.sh # 2. Ejecutar el asistente como superusuario (root / sudo) sudo ./setup-nginx-ssl.sh

El script solicitará interactiva o automáticamente:

  • Dominio o Subdominio: Dirección pública o interna del servidor (ej: `tu-dominio.com`).
  • Directorio Raíz Web: Ubicación de los archivos de la Landing Page (`/var/www/tu-dominio.com`).
  • Puerto Interno de Relevo: Puerto TCP de comunicación (`8443`).

El script generará automáticamente el bloque de configuración Nginx Dual en `/etc/nginx/sites-available/` y creará el certificado SSL con Certbot (Let's Encrypt):

# Bloque de configuración Nginx generado automáticamente: server { listen 80; server_name tu-dominio.com; root /var/www/tu-dominio.com; index index.html; location / { try_files $uri $uri/ =404; } location /ws { proxy_pass http://127.0.0.1:8443; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection 'upgrade'; proxy_set_header Host $host; proxy_read_timeout 86400s; proxy_send_timeout 86400s; } }

3. Ejecución del Servidor de Relevo

Inicia el servidor de sockets TCP en Node.js dentro de la carpeta `connecting-relay-server`:

# Iniciar el servidor Relay en segundo plano cd connecting-relay-server nohup node server.js > relay.log 2>&1 &

4. Errores Comunes y Revisiones de Diagnóstico

  • Error de Sintaxis en Nginx: Verifica la sintaxis del archivo ejecutando `sudo nginx -t`.
  • Puerto 8443 Ocupado o Bloqueado: Comprueba si el puerto está escuchando ejecutando `ss -tlnp | grep 8443` o `netstat -tlpn`.
  • Renovación de Certificado SSL: Para probar la renovación automática de Certbot ejecuta `sudo certbot renew --dry-run`.
  • Permisos de Archivos Web: Asegura los permisos del directorio web ejecutando `sudo chown -R www-data:www-data /var/www/connecting.abrdns.com`.

Manual del Cliente Remoto (.EXE)

1. Acceso Desatendido y Clave PSK Persistente

Para conectar de forma automática sin necesidad de confirmación manual:

  1. Abre Connecting.exe en el puesto remoto.
  2. Ve a la pestaña Configuración & Seguridad.
  3. Activa la opción "Permitir Acceso Desatendido directo con Clave PSK".
  4. Introduce tu contraseña en "Clave de Acceso Desatendido Personalizada".
  5. Esta clave se guarda automáticamente en `%APPDATA%\ConnectingNodes\custom_psk.dat`.

2. Hostname Automático y Alias Personalizados

Al conectarte a un equipo remoto, Connecting obtiene automáticamente su nombre de sistema (ej: DESKTOP-FINANZAS). En la pantalla principal, cada tarjeta del historial incluye la opción de asignar un nombre amigable como john-administracion.

3. Atajos de Teclado y Control Nativo

Desde el menú superior "Atajos & Acciones" dentro de la sesión remota, puedes enviar combinaciones directas de sistema como Win+R, Win+E, Ctrl+Alt+Supr y Ctrl+Shift+Esc.

Firma de Código y Advertencia Windows SmartScreen

Aviso sobre la firma digital del ejecutable Connecting.exe:
Al ser una herramienta portátil desarrollada de manera independiente, Connecting.exe no cuenta aún con un certificado comercial de firma de código de pago (como Sectigo, DigiCert o Azure Trusted Signing para desarrolladores independientes).

Debido a esto, el filtro Windows SmartScreen puede mostrar una ventana de alerta al ejecutar la aplicación por primera vez indicando "Editor desconocido" o "Windows protegió su PC". Esto ocurre en ejecutables independientes que no han adquirido un certificado de firma digital de pago.

Cómo continuar de forma segura: Haz clic en el enlace "Más información" dentro de la ventana de advertencia de Windows y presiona el botón "Ejecutar de todas formas". La aplicación es portátil, no requiere instalación ni modifica el registro de tu sistema.

Capacidades y Alcance de esta Versión (Release v1.0.1)

Lo que SI permite esta versión:

  • Control remoto fluido con transmisión de fotogramas de alta definición.
  • Portapapeles bidireccional en tiempo real para copiar y pegar texto entre local y remoto.
  • Chat interactivo en vivo integrado en la barra lateral.
  • Acceso desatendido persistente protegido mediante contraseña PSK única.
  • Aislamiento nativo de teclado impidiendo interferencias en el equipo local.
  • Widget flotante de sesión en el host para monitorear y finalizar la sesión en 1 clic.
  • Desconexión segura instantánea al cerrar la ventana o finalizar el soporte.

Lo que NO permite esta versión:

  • Transmisión de audio remoto en tiempo real (enfoque exclusivo en control gráfico y texto).
  • Transferencia masiva de archivos por arrastrar y soltar.
  • Cambio entre múltiples monitores en pestañas dentro de una misma ventana (se pueden abrir múltiples instancias ejecutables independientes).
